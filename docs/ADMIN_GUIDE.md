# Инструкция для администратора: актёры и сцены

Все действия выполняются в самом боте в Telegram. Команды работают только у администраторов, чей Telegram id прописан в `ADMIN_IDS`.

Пятнадцать имён уже заведены и видны на кнопках: Сиффреди, Синс, Видаль, Вудман, Дюпри, Кейран Ли, Мэдисон, Гарсиа, Манчини, Анджело, Феррара, Джорди, Дэнни Ди, Алекс Легенд, Мик Блю. Пока у имени нет фото, бот держит лицо только по имени. Чтобы лицо совпало, добавьте 2–4 референса через `/actors`.

## Какие фото подходят для актёра

- 2–4 фото на одного актёра. Лучше 3–4.
- Лицо крупно, анфас или в лёгкий поворот, хорошее освещение, без очков и головных уборов.
- Разные ракурсы и выражения лица, но один и тот же человек.
- Присылать как **фото**, а не как файл-документ. Одно фото в одном сообщении.

## Добавить фото уже созданному актёру

Стартовые имена уже включены и видны на кнопках даже без фото. Нового актёра бот показывает пользователям после двух фото.

1. Напишите боту `/actors`.
2. В списке нажмите на актёра. Значок ⛔ означает «выключен», число в скобках — сколько фото уже загружено.
3. В карточке нажмите **➕ Добавить фото**.
4. Пришлите фото по одному. После каждого бот ответит «Принято N/4».
5. Когда фото 2, 3 или 4, нажмите **✅ Готово**. При четвёртом фото бот завершит сам.
6. Бот ответит «Сохранено: N фото. Актёр включён». Всё, актёр появился у пользователей.

Если написано «Актёр выключен» — фото меньше двух, повторите шаг 3.

## Добавить нового актёра, которого нет в списке

1. `/actors` → **➕ Добавить**.
2. Введите имя для кнопки, например `Том Харди` или актёра взрослого кино.
   Имена больше не режутся стоп-листом.
3. Введите описание внешности по-английски, до 200 символов. Только внешность, например: `short dark hair, full beard, muscular build`.
4. Пришлите 2–4 фото по одному, затем **✅ Готово**.
5. Бот ответит «Актёр «…» добавлен». Он сразу включён.

## Выключить, включить или удалить актёра

- `/actors` → актёр → **Вкл/Выкл**. Стартовые имена уже включены. Если такое имя выключить, включить его обратно можно только после двух фото: бот подскажет, сколько не хватает.
- **🖼 Фото** — посмотреть загруженные референсы.
- **🗑 Удалить** — удаляет актёра вместе с фото, без подтверждения.

## Добавить сцену

1. `/scenes` → **➕ Добавить**.
2. Название для кнопки, например `Красная площадь`.
3. Описание сцены по-английски, до 300 символов: где стоят люди, что вокруг, какая одежда. Пример: `on Red Square in Moscow, winter, coats and scarves, snow falling`.
4. Ориентация кадра: **Вертикальная** для селфи и портретов, **Горизонтальная** для широких планов.
5. Фото места (по желанию) или **Без фото**.

Сцена сразу видна пользователям. Выключить или удалить: `/scenes` → сцена → **Вкл/Выкл** / **🗑 Удалить**.

## Реф-ссылки для партнёров

Партнёр (рефшарщик) получает ссылку вида `https://t.me/<бот>?start=ref_<код>`. Пользователь, пришедший по ней, привязывается к коду навсегда — при первом `/start`, ещё до экрана правил. Вторая ссылка привязку не перебивает. Выплаты партнёрам считаются и делаются вручную вне бота.

Команды администратора:

- `/ref_add <код> <telegram_id партнёра|-> <название>` — создать ссылку и получить её текст. Код: латиница, цифры и `_`, от 3 до 32 символов. Поставьте `-` вместо id, если партнёру не нужен доступ к своей статистике.
- `/refs` — все ссылки со статистикой: 👥 приведено пользователей (✅ из них приняли правила) · 💳 платящих · ⭐ доход в Stars · ₽ доход Tribute · 🖼 генераций. Выключенные ссылки помечены ⛔.
- `/ref_off <код>` — выключить: по ссылке больше никто не привяжется, уже привязанные остаются и продолжают считаться. `/ref_on <код>` — включить обратно.

Партнёр пишет боту `/partner` и видит только свои ссылки: сами ссылки и те же цифры за всё время и за последние 7 дней. Команда не админская, но доступна только тем, чей Telegram id указан в `/ref_add`. Остальным бот отвечает «У вас нет реф-ссылок.».

Общее число приведённых пользователей есть и в `/stats` — строка «🔗 Рефералов всего».

## Вкладка «📊 Метрики» в мини-приложении

Кнопка «Кабинет» рядом с полем ввода (или «🧭 Кабинет» под баннером меню) открывает мини-приложение. У админов из `ADMIN_IDS` в нижней панели появляется третья вкладка «📊 Метрики» — то же, что `/stats`, только наглядно: плитки «всего» (пользователи, принявшие правила, активные подписки, генерации, кристаллики на руках, пришедшие по реф-ссылкам), приход за сегодня / 7 дней / 30 дней отдельно в Stars и рублях вместе с расходом на Runware, столбчатый график за последние 30 дней (переключается между новыми пользователями, фото, Stars и рублями) и таблица по всем реф-ссылкам с кнопкой «Копировать» у каждой ссылки. Цифры считаются по UTC, как и в `/stats`. У обычных пользователей этой вкладки нет, а запрос к метрикам напрямую возвращает отказ.

## Если что-то пошло не так

- Бот пишет «Описание не прошло стоп-лист» — в тексте есть слово из запрещённого списка (нагота, порнолексика, насилие, несовершеннолетние). Купальник и позу писать можно. Перепишите описание.
- Имена актёров, в том числе из взрослого кино, стоп-листом не режутся.
- Бот молчит на фото — вы не в режиме добавления. Начните заново с `/actors`.
- Хотите выйти из диалога — команда `/cancel`.
- Полный список команд — `/admin`.
