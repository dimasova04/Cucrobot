# Инструкция для администратора: актёры и сцены

Все действия выполняются в самом боте в Telegram. Команды работают только у администраторов, чей Telegram id прописан в `ADMIN_IDS`.

## Какие фото подходят для актёра

- 2–4 фото на одного актёра. Лучше 3–4.
- Лицо крупно, анфас или в лёгкий поворот, хорошее освещение, без очков и головных уборов.
- Разные ракурсы и выражения лица, но один и тот же человек.
- Присылать как **фото**, а не как файл-документ. Одно фото в одном сообщении.

## Добавить фото уже созданному актёру

Актёр без двух фото выключен и не виден пользователям, пока фото не добавят.

1. Напишите боту `/actors`.
2. В списке нажмите на актёра. Значок ⛔ означает «выключен», число в скобках — сколько фото уже загружено.
3. В карточке нажмите **➕ Добавить фото**.
4. Пришлите фото по одному. После каждого бот ответит «Принято N/4».
5. Когда фото 2, 3 или 4, нажмите **✅ Готово**. При четвёртом фото бот завершит сам.
6. Бот ответит «Сохранено: N фото. Актёр включён». Всё, актёр появился у пользователей.

Если написано «Актёр выключен» — фото меньше двух, повторите шаг 3.

## Добавить нового актёра, которого нет в списке

1. `/actors` → **➕ Добавить**.
2. Введите имя для кнопки, например `Том Харди`.
3. Введите описание внешности по-английски, до 200 символов. Только внешность, например: `short dark hair, full beard, muscular build`.
4. Пришлите 2–4 фото по одному, затем **✅ Готово**.
5. Бот ответит «Актёр «…» добавлен». Он сразу включён.

## Выключить, включить или удалить актёра

- `/actors` → актёр → **Вкл/Выкл**. Включить актёра без двух фото нельзя, бот подскажет, сколько фото не хватает.
- **🖼 Фото** — посмотреть загруженные референсы.
- **🗑 Удалить** — удаляет актёра вместе с фото, без подтверждения.

## Добавить сцену

1. `/scenes` → **➕ Добавить**.
2. Название для кнопки, например `Красная площадь`.
3. Описание сцены по-английски, до 300 символов: где стоят люди, что вокруг, какая одежда. Пример: `on Red Square in Moscow, winter, coats and scarves, snow falling`.
4. Ориентация кадра: **Вертикальная** для селфи и портретов, **Горизонтальная** для широких планов.
5. Фото места (по желанию) или **Без фото**.

Сцена сразу видна пользователям. Выключить или удалить: `/scenes` → сцена → **Вкл/Выкл** / **🗑 Удалить**.

## Если что-то пошло не так

- Бот пишет «Описание не прошло стоп-лист» — в тексте есть слово из запрещённого списка (эротика, нагота, насилие). Перепишите описание.
- Бот молчит на фото — вы не в режиме добавления. Начните заново с `/actors`.
- Хотите выйти из диалога — команда `/cancel`.
- Полный список команд — `/admin`.
